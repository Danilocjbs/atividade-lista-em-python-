# atividade-lista-em-python- 
## 🚀 Revisão de Python - Semana 1

Este repositório contém meus códigos de estudos, práticas e desafios desenvolvidos durante a **Semana 1 de revisão de Python**. O objetivo principal foi consolidar os fundamentos da linguagem, estruturas condicionais, laços de repetição e manipulação de listas.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3.x
* **Ambiente:** Google Colab / Jupyter Notebook

---

## 📌 Funcionalidades & Conceitos Praticados

### 1. Variáveis e Entrada de Dados
* Entrada dinâmica de dados com `input()` e conversão de tipos (ex: `int()`, `float()`).
* Exibição formatada de textos utilizando f-strings.

### 2. Manipulação de Listas
* Criação de listas e controle de estoque básico.
* Métodos de manipulação de listas como `.append()` para adicionar elementos e `.pop()` para remover o último item.
* Uso da função `len()` para verificar se a lista de estoque está vazia.

### 3. Estruturas de Repetição (`for` & `zip`)
* Iteração sobre listas utilizando o laço `for`.
* Iteração paralela sobre múltiplas listas (produtos e preços) usando a função `zip()`.

### 4. O Desafio FizzBuzz 🎮
Implementação do clássico desafio de programação **FizzBuzz** com a seguinte regra:
* Se o número for divisível por **3**, exibe `fizz`;
* Se for divisível por **5**, exibe `buzz`;
* Se for divisível por **3 e 5** ao mesmo tempo, exibe `fizzbuzz`;
* Caso contrário, exibe o próprio número.
